# Windows Administration Home Lab

## Overview
Built and administered a Windows 11 virtual machine using UTM to practice system administration, user management, permissions, and troubleshooting.

## Skills Demonstrated
- User management
- Group management
- NTFS permissions
- PowerShell
- Windows administration

## Tools Used
- Windows 11
- UTM
- PowerShell
- Command Prompt

## Key Tasks
- Created local users and groups
- Configured folder permissions
- Performed system administration tasks
- Practiced troubleshooting with Windows tools
